**penjelasan singkat kode**

- def berfungsi sebagai menerima dua data masukan (mobil dan motor) jika mobil biaya tarifnya 5000 perjam, jika motor biaya tarifnya 3000 perjam

- while true berfungsi sebagai perulangan agar bisa memilih menu berulang kali sampai user/sistem memilih untuk berhentti. Dan jika user memilih angka yang tidak ada di menu maka tidak akan bisa dan disuruh input angka menu kembali

- input dan logika perhitungan, jika pengguna memilih 1 (mobil) atau 2 (motor), maka program akan meminta input angka jam masuk dan jam keluaar. lama parkir di hitung seperti jam_keluar - jam_masuk, setelah itu sistem akan menghitung dan menampilkan struk
